# Branding Service Brief

## Business objective

A premium "tech-luxury di prossimità" identity that makes a vending product feel
like furniture and supports B2B trust (hosts, PMs, investors).

## Audience and context

Primary: hosts/property managers (buyers). Secondary: investors (Data Room), guests.
Italian first, EN-ready for CH/EU expansion.

## Accepted constraints

- Wordmark `SUITE` (Unbounded 700) + `BOX` (Unbounded 300), uppercase, monochrome; never invert weights.
- Type system: Unbounded (display) + Inter (text/UI); no serifs.
- Visual system v2 "**Daylight**" (paper base, ink, blue accent, green/amber/coral
  functionals) — the earlier navy/gold palette is deprecated.
- Tone: clear, concrete, hospitable-professional; no gratuitous superlatives.

## Deliverables

Brand reference (`SUITEBOX_Brand.md`) · brandbook HTML · logos/monograms SVG+PNG ·
photo asset plan — all produced; alignment pass pending (pitch deck still uses Georgia).

## Definition of done

All live surfaces (site, deck, dashboards, kit) on the Daylight system and the
Unbounded/Inter pair; deprecated palette fully retired.

## Review rule

`reviewer_type: internal` — Alex holds final taste authority.
